Expo expects the following assets (create with any 1024x1024 PNG for icon, etc.):

- icon.png (1024x1024 recommended)
- splash.png (1284x2778 or similar)
- adaptive-icon.png (1024x1024, foreground)

Or run `npx create-expo-app@latest dummy --template blank` and copy the `assets` folder from `dummy` into this `mobile` folder.
